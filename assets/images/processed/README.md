# Processed images

EXIF-stripped, web-sized images that are committed and shipped with the
site. Produced by `tools/process_images.py` from sources in `../raw/`.

Filenames must be **neutral and location-agnostic** — no climbing area
names, no personal names other than `hester`. See
`../../../IMAGE_ASSET_PLAN.md` §2 for the full naming and privacy rules.
